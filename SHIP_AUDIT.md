## Fix-before-ship — resolved

### Permissions / runtime
- `POST_NOTIFICATIONS` and `VIBRATE` declared at the top of `AndroidManifest.xml`.
- Removed bogus `NSUserNotificationsUsageDescription` from `ios/Runner/Info.plist`. iOS notifications are gated by the runtime prompt only; no Info.plist key is required.

### Branding / first frame
- Android cold-launch background flipped from `Theme.Light.NoTitleBar` → `Theme.Black.NoTitleBar` in both `values/styles.xml` and `values-v31/styles.xml` so light-mode-OS users don't see a white flash on a dark-only app.
- Android 12+ `SplashScreen` API styled with `windowSplashScreenBackground = #131316` + the mountain icon. `values-v31/styles.xml` (+ `values-night-v31/styles.xml`) generated by `flutter_native_splash`.
- Android pre-12 splash: `drawable/launch_background.xml` re-rendered with the bundled splash background.
- `CFBundleName` lowered `peak` → `Peak` in `ios/Runner/Info.plist`.
- iOS `LaunchScreen.storyboard` root-view `backgroundColor` set to `#131316` (defensive — the `LaunchBackground` image still covers the screen).

### Backup contract
- `<application android:allowBackup="true" android:fullBackupContent="@xml/backup_rules" android:dataExtractionRules="@xml/data_extraction_rules">`.
- `res/xml/backup_rules.xml` (API < 31) + `res/xml/data_extraction_rules.xml` (API 31+) explicitly include `peak.sqlite`, the WAL/SHM files, and SharedPreferences so a reinstall restores workout history.

### Release-build hygiene
- `isMinifyEnabled = true`, `isShrinkResources = true` on release.
- `proguard-rules.pro` ships with keep-rules for `flutter_local_notifications` (Gson reflection) + a defensive keep on the Flutter platform-interface namespace.
- Release APK builds clean: `app-release.apk 57.4 MB`, debug-signed when no keystore is present.

## Remaining one-time setup (off-repo)

1. **Generate the upload keystore once** (Mac/Linux/Windows with JDK):
   ```
   keytool -genkey -v -keystore android/peak-upload-key.jks \
       -keyalg RSA -keysize 2048 -validity 10000 -alias peak-upload
   ```
2. **Drop `android/key.properties`** with `storeFile=../peak-upload-key.jks`, the password, and alias — see `android/key.properties.example`. Both files are gitignored.
3. **Build the AAB** for Play upload:
   ```
   flutter build appbundle --release
   ```
4. **iOS:** open `ios/Runner.xcworkspace` in Xcode, archive, upload. The Privacy Manifest is already in the bundle target. Provisioning + signing identity remain the only manual steps.
